## Key Features

1. **Simultaneous Multi-Angle Upload**:
   - Upload unlimited plant photos simultaneously from multiple perspectives (Overview, Leaf close-up, Leaf underside, Stem/Base, Flower/Bud, Soil/Roots).
   - Drag-and-drop, camera capture, or multi-select file dialog.
   - Interactive thumbnail gallery with angle switcher, individual photo removal, and high-resolution lightbox inspection.

2. **Species-Specific Remedies under Care Snapshot**:
   - Tailored specifically to the exact plant species (Tulsi, Hibiscus, Rose, Snake Plant, Money Plant, Tomato, Aloe Vera, Mint, Curry Leaf, Monstera, Chilli, etc.).
   - **Tulsi**: Sacred Manjari de-heading, food-safe neem oil spray at dusk, root aeration, morning sun alignment.
   - **Hibiscus**: High-potassium banana peel tea, mealybug eradication with 70% alcohol swabs, hard pruning on new wood, saucer drainage regulation.
   - **Rose**: Black spot surgical leaf sanitation, deadheading above 5-leaflet nodes, baking soda organic fungicide.
   - **Snake Plant**: Emergency root rot rescue with cinnamon powder, strict 3–4 week drought interval, porous gritty mix.
   - **Money Plant (Pothos)**: Broad leaf microfiber dusting, water propagation at nodes, variegation lighting.
   - Plus detailed Care Snapshot for Watering, Photoperiod, Pest Defense, and Soil Nutrition.

3. **Strict Non-Plant Validation (`"this is not a valid image"`)**:
   - Neural classification (MobileNet ImageNet weights) + Canvas botanical pigment & vegetation chromatic heuristics.
   - Detects non-plant uploads (automobiles, dogs, cats, shoes, electronics, furniture, household objects).
   - Automatically displays `"this is not a valid image"` alert banner, marks invalid gallery cards, and prevents non-plant diagnoses.
